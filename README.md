  </p>
  <p>
    단편영화, 다큐멘터리, 예능, 뮤직비디오, 모션그래픽과 외주 영상 편집 등<br>
    다양한 작업을 통해 콘텐츠의 목적과 시청자의 관점에 맞는<br>
    결과물을 만들기 위해 노력하고 있습니다.
  </p>
